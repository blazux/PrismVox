Voice & greeting

Speech providers
Voice — all calls
Voice selection is saved immediately.
Read this while recording
“Hello and welcome! How can I help you today? Tell me what you need, and I will make sure your message reaches the right person.”
Record yourself reading the phrase above (5–10 s, clear voice, no background noise) — or upload a clean pre-recorded .wav — it covers varied sounds and natural intonation for better cloning. Play it back, name the voice, then add it. The change is immediate, no restart. (Microphone only accessible over https or on localhost — upload a file instead if you can't switch.)
Spoken phrases Phrases spoken by the code during the call flow. always = always played at this point of the call. fallback = the LLM normally handles it; this phrase only fires as a fallback (the LLM didn't, or failure/timeout).

Pronunciation & transcription

Domain vocabulary shared by transcription (STT) and speech synthesis (TTS). Changes take effect on the next call — no restart. Separate terms with spaces or commas.

✓ Saved — active on the next call.

Transfers & directory

Phone directory

Enabled contacts are injected into the context on every call to allow transfers by name.

+ Add a contact

Knowledge collections

Semantic search (embeddings + pgvector): on each turn, only the passages most relevant to the caller's question are injected. Documents are indexed automatically on upload. Formats: .txt, .md, .pdf.

+ New collection

MCP Servers

Connect tool servers over HTTP or SSE. Changes take effect on the next call or text turn; an active call keeps its current tools.

+ Add an MCP server

Outbound calls

The agent dials these calls itself (one at a time, never during another call) and carries out the described mission. The outcome is summarized after each call.
